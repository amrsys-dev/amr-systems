## 1. Главное
- **Ничего в production без слова Мурада «выкатывай».** Только PR + тестовая ссылка (preview) + скриншоты.
- **Одна задача - один PR.** Не трогать то, о чём не просили. Не «улучшать» соседние экраны.
- **Не ломать работающее.** Перед PR: тесты и сборка зелёные (команды ниже). Если тест падал до вас - сказать об этом.
- **Удалять что-либо** (таблицы, данные, сервисы, ветки с чужой работой) - только с согласия Мурада и после копии.
- **Секреты** (токены, пароли, строки подключения к базе) не писать в чат, не коммитить, не печатать в логи.
- Не дублировать уже сделанное: сначала найти в коде, нет ли этого (например, диспетчер такси уже есть).
- В конце работы - короткий отчёт на русском: что сделано, ссылка на превью, что проверить, что не сделано.

## 2. Тексты
- Тире только короткое «-», никогда длинное «—».
- Языки AMR: ru, ar, en, uz, tg (+ hi, bn, ur там, где уже есть). Язык по умолчанию - язык телефона («Авто»).
- Каждый новый текст - сразу на всех языках приложения. Никаких английских слов в русском интерфейсе (статусы, ошибки).
- Валюта - SAR. Даты и время - Эр-Рияд (UTC+3).

## 3. Интерфейс (стандарт AMR)
- Название приложения крупно в шапке, монограмма AMR меньше рядом.
  Монограмма - стандартная зелёная с золотой каймой (amr-service-hub/brand/amr-monogram/), без глянца и меди.
- Язык и тема - по одной кнопке в шапке с выпадающим меню. Фильтры (район, ♂/♀/семья и т.п.) - тоже выпадающие меню, не ряды кнопок.
- Кнопки: обычного размера (высота 44-52 px), текст по центру, не «огромные» и не вылезающие за край.
  Скруглённый прямоугольник, как остальные кнопки. Одна главная кнопка на экране.
- Меню открывается под своей кнопкой; жест «Назад» на телефоне закрывает меню/панель; одна панель за раз.
- Меньше шагов и кнопок: каждый лишний шаг теряет пользователей.
- Логотипы соцсетей - только оригинальные SVG, не нарисованные копии.
- Должно быстро работать на дешёвых телефонах: без тяжёлых эффектов, стекло только CSS и не на каждой карточке.
- У каждого приложения свой акцентный цвет (иконка, главная кнопка):
  AMR ID - чёрный с золотом, SELF - зелёный, Safar - изумруд/бирюза, Bazar - фиолетовый, AMR Cut - синий, Hostel - терракота.
- Профиль: сверху AMR ID (вход и коротко что это), ниже карточка «Другие приложения AMR».
- Проверять на телефоне шириной 360-420 px, светлая и тёмная тема.

## 4. Экосистема
- Портал amrsys.net (amr-systems, products.json - реестр продуктов). Приложение - <slug>.amrsys.net, свой проект Vercel.
- Вход - только через AMR ID (id.amrsys.net). «Выйти» в приложении выходит только из этого приложения.
- Подписки: бесплатно навсегда с ограничениями по функциям + Pro; 14 дней Pro один раз на аккаунт.
  Платят те, кто зарабатывает (водитель, владелец хостела, магазин). Гости и пассажиры - бесплатно.
- Аккаунты не смешиваются: каждое приложение видит только свои данные о человеке.
- База: Neon (тариф Launch) - запросы экономно, опрос сервера только когда экран открыт, не чаще 30-60 сек.
