# AMR Systems — архитектура портала

Источник правды: брендбук v1.2, разделы 25 (портал и страницы продуктов) и 26 (реестр продуктов).

- `amrsys.net` — портал (статический HTML, ~6 КБ gzip на страницу).
- `<slug>.amrsys.net` — страница продукта; один проект Vercel, правило host → `/p/<slug>/` в `vercel.json`.
- Приложения — отдельные проекты и адреса (`app_url`), портал их не встраивает и не замедляет.
- Вход и регистрация — только в AMR ID / SELF, на портале аккаунтов нет.
- Статусы честные: `live` только после выпуска в продакшн.
